# Data Quality Rules

## Purpose

This document defines the data quality rules used to assess the synthetic healthcare patient data generated by Synthea.

The rules are designed to evaluate:

- Completeness
- Uniqueness
- Validity
- Consistency
- Plausibility

No real patient data is used.

---

## Data Quality Principles

A missing or unusual value is not automatically an error.

Before defining a value as invalid, the following should be considered:

1. What does the source system intend the value to represent?
2. Is the value structurally valid?
3. Is the value logically consistent with related fields?
4. Is the value required for downstream analysis?
5. Can the value be corrected without inventing information?

Data should not be removed simply because it appears unusual.
