# Healthcare Data Quality Lab

## Overview

This project is part of my modern data analytics portfolio.

The goal is to build a healthcare analytics workflow using synthetic healthcare data and demonstrate practical skills in data quality, data profiling, SQL, data modelling, analytics engineering, semantic modelling, business intelligence, and AI-assisted analytics.

No real patient data is used.

## Project Goals

- Explore and profile healthcare data
- Identify data quality issues
- Define and implement data quality rules
- Clean and validate data
- Use Python and SQL for analysis
- Build reproducible analytics workflows
- Develop a modern analytical data model
- Document assumptions and decisions
- Explore AI-assisted analytics techniques

## Technology

The project will progressively use:

- Python
- SQL
- Git
- GitHub
- DuckDB
- Synthea
- Jupyter
- Power BI
- Microsoft Fabric
- AI-assisted analytics tools

Tools will be introduced gradually as the project develops.

## Data

The project uses synthetic healthcare data generated using Synthea.

No real patient information is used.

## Project Status

🚧 Project setup in progress.

## Learning Objectives

This project is designed to demonstrate how traditional BI experience can be extended into modern analytics engineering, semantic modelling, cloud analytics, and AI-enabled analytics.
